{{- if .Values.ingress.enabled }}

Reachable via ingress:
  http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}{{ .Values.ingress.path }}graphql

No ingress is enabled. Port-forward to reach it:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "primetime-server.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # then POST to http://localhost:{{ .Values.service.port }}/graphql
{{- end }}

{{- end }}
{{- end }}

  kubectl --namespace {{ .Release.Namespace }} exec deploy/{{ include "primetime-server.fullname" . }} -- ./admin list-users
